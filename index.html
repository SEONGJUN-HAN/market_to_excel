지마켓 · 옥션 · 11번가 견적서를 에듀파인 물품내역 서식으로 정리

브라우저 내 처리 · 무설치

업로드한 견적서는 이 브라우저 안에서만 분석됩니다. 파일도 API 키도 별도 서버로 전송·저장되지 않습니다. 결과는 에듀파인 업로드용 서식과 검토용 보고서로 내려받을 수 있습니다.

1견적서 파일 업로드
파일을 끌어다 놓거나 클릭하여 선택하세요
지마켓 · 옥션 (.xls) / 11번가 (.pdf) — 여러 개 동시 가능
    2Gemini API 키 (선택 · 품명 자동 정리)

    품명을 더 깔끔하게 정리하려면 본인 Gemini 키를 넣으세요. 키는 이 브라우저에서 구글로 직접 전송되며 서버를 거치지 않습니다. 키 발급 →

    무료 티어 키는 요금이 청구되지 않습니다. 결과의 "약 N원"은 유료 키 기준 참고 비용입니다. 기본값 flash + low는 옵션·규격까지 깔끔하게 정리해 공문서에 적합합니다(견적서 1건당 유료 기준 15원 안팎). 대량·저비용이 우선이면 flash-lite로 바꾸세요. 넣기 전 검토용 보고서의 원문대조로 확인을 권장합니다.

  개인정보 및 처리 안내 · 모든 파일 분석과 엑셀 생성은 사용자 브라우저(WebAssembly) 내에서 수행되며, 견적서 파일과 API 키는 외부 서버로 전송·저장되지 않습니다. Gemini 품명 정리를 사용하는 경우에 한해, 품명·규격 텍스트가 사용자의 키로 Google API에 직접 전송됩니다.
    
  정리된 품명·규격은 가독성을 위해 재작성된 값이므로, 공문서 반영 전 원문대조 시트로 확인하시기 바랍니다.
